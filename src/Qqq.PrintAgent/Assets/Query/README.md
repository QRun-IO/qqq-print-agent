QRun.IO and bundled unmodified for the About dialog.

The About dialog scales the image uniformly on a white card. It does not
download or alter the artwork, replace customer branding, or change the
application and tray icons. Query remains QRun.IO/QQQ branding; this provenance
note does not grant separate trademark permissions or relicense the artwork.
