# Baseline audit for 2.0 — 2026-11-10

Status: baseline. Four independent read-only reviews of `main` at `c4b1496` (four commits behind the release at the time; the missing commits added provider sign-out). The 2.0 release is done only when fresh reviewers, using the rubric below, score every criterion under code, design, architecture and security at 9 or better. This file is the rubric and the starting point; it is updated as findings close, and the re-audit is appended at the end.

## How to re-run it

One reviewer per area, read-only, with no access to this file's scores until they have written their own. Each reads the standards first (`coding/README.md`, `coding/csharp-dotnet.md`, `testing.md` in the KofTwentyTwo standards repository; the repo-level reviewer also reads `ci-cd.md`, `repository.md`, `releases.md`, `dependencies.md`), then every source file in scope, and scores each criterion from 1 to 10 with a `file:line` citation. A finding must be verified by reading the code, not inferred from a name. Reviewers say what they did not read.
