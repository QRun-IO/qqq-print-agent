# Windows printing audit

Status: independent baseline scan and source remediation review complete; final packaged and installed upgrade qualification remains pending. Target: 0.1.8-rc.1. The currently installed/public baseline remains 0.1.7-rc.1. Earlier audit and CI guard commits passed hosted checks; final remediation commits require fresh hosted verification.

## Corrected findings

| Area | Defect | Correction |
| --- | --- | --- |
| Local management | Unterminated requests allocated before size checks; a stalled reader could block a response | Bounded newline frames and cancellation for both sides, including diagnostic replies |
| Local peer identity | Clients could transmit enrollment data to a substitute pipe server | Authenticate the connected process against the installed LocalSystem service before transmitting; retain process/service handles, use non-impersonating explicit access rights and retain the first pipe instance |
| Machine state | A precreated owner or protected child could retain control despite a restrictive root DACL | Reject untrusted owners, access grants and links throughout adopted state before privileged use; apply the same invariant to direct and branded installation |
| Sign-in startup | Task XML could be replaced between creation and registration | Create within validated machine state and hold a read handle denying writes/deletion while Task Scheduler reads it; verify the resulting definition |
| HTTP | Control responses used a large default buffer; a streamed document body could outlive the request timeout | 2 MiB control-response bound and a deadline covering the complete document download |
| History | Valid job/printer metadata was truncated at 256 characters | Preserve the supported 1024-character bound across persistence/restart |
| Storage | Failed schema initialization could leak a SQLite connection | Dispose across the entire initialization failure path |
| Throughput | Every successful job incurred an extra configured idle delay | Drain successful work, yield between jobs, retain idle/error/pause backoff |
| Companion lifecycle | Pending UI work could resume after tray resources were disposed | Idempotent disposal and lifetime checks around asynchronous completions |
| Reprint consent | A failed job could retain known submission risk, but the client omitted the consent flag despite showing the risk confirmation | Send explicit duplicate-risk consent only after the operator accepts that confirmation |
| Packaging | Old files could survive publish and enter WiX harvesting; payload versions could disagree | Fresh output directories, locked restore and source/MSI/component version checks |
| Release | Publication did not require every security/script gate or build provenance | Gate publication, verify promoted checksums and generate GitHub artifact attestations |
| Test evidence | Solution and direct-test platform paths could select stale binaries with `--no-build` | Build the direct test invocation's platform and isolate each run's results |
| Script gate | PSScriptAnalyzer 1.25 intermittently crashes inside command metadata lookup when rules run concurrently | Run all 75 rules sequentially per file; retain every configured check and fail on engine errors |

## Local evidence

The fresh isolated source gate passed **249 tests: 66 Core and 183 Windows/CLI**, with zero warnings/errors and no skipped tests. Installer sequencing then received a focused regression update. Named-pipe tests use real randomly named local pipes and verify that a substitute receives zero request bytes; backlog tests use fake printers and HTTP. Existing 10,000/30,000-row history tests are included. All 12 PowerShell gate tests, branding dry runs and all 75 analyzer rules passed. These checks do not invoke a live installer or print documents.

A fresh reviewer identified an access-rights compatibility regression in the pipe fix; the client now requests explicit read/write rights while retaining peer authentication. Parent review also corrected MSI deferred-action ordering: the preflight executes in the installation script before old-product removal, with removal inside the rollback transaction. Actual packaged formatting, component identities and installed behavior remain separate qualification gates. A long temporary build path exceeded a Windows tool limit; a fresh shorter snapshot passed without a project-file workaround.

Coverage is reported under the [prerelease exception](adr/0002-prerelease-quality-and-packaging.md), not presented as a 100% gate. Core-suite coverage was 79.47% lines / 63.2% branches. The Windows/CLI suite measured Windows 59.75% / 57.39%, CLI 29.26% / 39.65%, and Core 41.05% / 24%. These overlapping measurements must not be averaged.

The recursive analyzer failure reproduced locally and in hosted CI as `CommandInfo.get_Parameters` / `UseCorrectCasing`, matching the [upstream race report](https://github.com/PowerShell/PSScriptAnalyzer/pull/2206). Sequential execution passes all 75 rules across the current 11 scripts. The 12 PowerShell gate tests include missing inputs, bad command casing, aliases and machine-state security. No rule was disabled or engine exception ignored; hosted validation passed for the analyzer correction before the final machine-state changes.

## Remaining qualification

The independent scan covered a frozen pre-audit baseline; subsequent fixes received targeted tests and a fresh independent source review. Real in-app update handoff, positive installed service authentication, hostile precreated-state installation, rollback, installed close-during-I/O behavior, reboot/sign-in/recovery, broad accessibility/resize coverage, remote HTTPS deployment and sustained physical throughput remain unqualified. Computer-use inspection of the installed elevated companion was limited by Windows integrity boundaries. Prior user-confirmed laser PDF and Zebra ZPL/PDF output remains evidence for 0.1.7 and its tested driver configuration.

The user accepts unsigned prereleases. Checksums and GitHub provenance are distinct from Authenticode signing. Retained duplicate-prevention summaries intentionally grow; operators must monitor disk space. Source tests and this audit do not establish absence of defects or a numerical quality score.
